
# 🎮 Sistema de Gerenciamento de Campeonatos de E-Sports

Trabalho prático desenvolvido para as disciplinas de Estruturas de Dados I e Programação Orientada a Objetos (2º Período do curso de Tecnologia em Análise e Desenvolvimento de Sistemas - IFTO Campus Araguaína, 2026/2).




## Sobre o projeto

O objetivo deste projeto é desenvolver um sistema em Java para gerenciar a tabela de classificação e o histórico de partidas de um campeonato de E-Sports. O sistema consolida conceitos fundamentais de POO e Estruturas de Dados, aplicando manipulação de vetores estáticos, métodos manuais de busca e algoritmos de ordenação. Sem o uso de bibliotecas nativas de ordenação ou busca da API do Java.
